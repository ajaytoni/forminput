creating a simple webpage

A simple web page is a foundational digital document,typically built using html(structure),css(styling), and sometimes basic javascript, the core information,utilizing headings(h2),(h3),text,images, and perhaps lists.the bottom section containing copyright information, contact details, and social media links.

essentional design principles they are whitespace, readiability,mobile-first,simplicity.headers contains the site name or logo and navigation links to other parts of the site.the first thing users see.it should include a clear heading(h1).

some core elements of a simple webpages,headers,hero section(above the fold),main content area,call to action,footer.
